# iso-diagram — 三级管线轴测示意图模块

## 当前画法（2026-09-13 最新用户修正）

采用45°正面斜轴测，X水平、Y向右上45°、Z竖直。主管至支管的连接整段平行Z轴；三通在下、阀门在立管中部、支管在上。为满足此展开示意，支管及所属滴灌带整体作显示平移，偏移保存在 viewState.branchOffsets；配件拾取须扣除该偏移。原平面坐标与水力计算不变，展开图不用于平面放样。

自动阀门采用沿管段旋转的通用对顶三角符号，黑色单线按线宽区分管级，管径文字沿用原数据。无真实标高或比例，图中明确注明待设计确认。下文旧2:1投影、彩色圆点和旧接管段描述为历史记录，不再代表当前渲染。RISE45仅保留API兼容，渲染不再使用。验证：node --test tests/iso_diagram.test.cjs（43项断言）。

三级管线平面图 → 工程轴测示意图的**纯表达转换**模块。只读平面图几何，不参与任何水力计算。

## 数据契约（只读）

数据源：`window.tlDiagramData`，由 `index.html` 的 `tlAutoGenerate()` 末尾导出（version 1，单位：米，世界坐标 local-2d）。

```js
{
  version: 1, world: 'meter', generatedAt: ISO字符串,
  plot: { w, h },                      // 地块名义尺寸（米）
  poly: [{x,y}...],                    // 地块边界
  zones: { cols, rows, xPos[], yPos[], xPlan[], yPlan[], xSrc[], ySrc[] },
  mainPipes:  [[{x,y},{x,y}]...],      // 主管（每分区一条）
  branchPipes:[[{x,y},{x,y}]...],      // 支管
  valves:     [{x,y,ax,ay}...],        // 平面图已有阀门（ax/ay=45°斜拉连接点，在主管上）
  dripTapes:  [[{x,y},{x,y}]...],      // 滴灌带示意线
  frontPipe:  [{x,y},{x,y}] | null,    // 总管
  sourcePos:  {x,y} | null,            // 水源/泵
  meta: { zoneCount, pump:{flow,head,power}, pipes:{front,main,branch} }  // 文本快照
}
```

## 层级映射（总管/主管埋地，支管地表）

| 平面图数据 | 轴测高度 z（表达参数，非高程） | 颜色 |
|---|---|---|
| 总管 frontPipe | **−1.5（埋地）** | 橙 #f97316 |
| 主管 mainPipes | **−1.0（埋地）** | 蓝 #185FA5 |
| 支管 branchPipes | 0.3（地表） | 绿 #16a34a |
| 滴灌带 dripTapes | 0（地面） | 浅青虚线 |
| 阀门 | 所在管高（接入阀 −0.55 埋地 / 出水阀 0.3 地表） | 红 #ef4444 |
| 水源 | 0.9 | 琥珀 P 符号 |

• 总管/主管为埋地管，绘制于地面之下（z<0，先画、被地表图元覆盖），**位于支管下方**；
  支管/滴灌带为地表管。埋深数值仅为上下表达，不代表真实高程。

投影：2:1 工程轴测 `sx=(x−y)·k，sy=(x+y)·k/2 − z·k`，k 按包围盒自适应。

埋地出管画法（2026-09-13 用户指定，垂直立管式）：主管↔支管阀门的连接不再用三通→阀门斜拉线
（屏幕角度随阀位漂移、与主管近乎平行），改为**三通处垂直立管升至地面 + 地面水平管接阀位正下方**，
再由浅灰虚线立杆升至阀门符号——工程图最常见的埋地出管表达。总管↔主管接入阀（−0.55 埋地）不适用，
仍走「总管→接入阀→主管」接入段画法。
