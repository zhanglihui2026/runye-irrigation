## 一、这是什么

在轴测图参数编辑（editor.js）之上的**拓扑级**编辑能力。与参数编辑的区别：
参数编辑只改图纸标注（口径/阀型等），不动物管拓扑；本模块维护一份**独立的施工管网模型**，
插阀门会把一段 20m 的管真的拆成 8m + 12m 两段（带真实接口），改尺寸会沿约束链传播。

**本轮重点：真实工程高程与轴测显示层高彻底分离。** 显示层高 `z`（主管 -1 / 支管 +0.3，
仅用于轴测绘制分层）不再是连接依据；连接/截断一律以**真实工程高程 `elevation`** 判断，
未确认（`null`）时拒绝自动驳接，由左栏入口人工确认。

- **模型**：`ConstructionNetwork`，API：`fromPlan / insertFittingOnSegment /
  setSegmentLength(segmentId, length, {anchor|moveEnd|moveFitting}) / addBranch / moveFitting /
  pin / unpin / connectPorts /
  planExtend / applyExtend / planTrim / applyTrim /
  beginEdit / commitEdit / cancelEdit /
  undo / canUndo / serialize / deserialize / computeStats / validate`。
  改长 / 移动成功时返回随动报告：`movedFitting`、`affectedFittings`（被带动的配件）、
  `absorbedSegments`（自动重新切分的锚固管段）。
- **两段式编辑**：`planExtend` / `planTrim` **只算不改**（供预览，无副作用）；
  `applyExtend` / `applyTrim` 在 `beginEdit…commitEdit` 事务内**原子提交**。
  预览不分配稳定 ID、不动 `seq`、不入撤销栈；确认提交 = 一步撤销。
- **真实高程**：`Fitting.elevation`（`number` 米 / `null`=未确认）。
  `fromPlan` 一律置 `null`（不默认 0、不继承 `z`）；老存档载入时缺字段 → 迁移为 `null`。
  延伸/交叉截断要求两端 `_elevCompatible`（都已确认且同高程）否则拒绝。
- **约束传播**：`_propagate(seed)`，固定端为墙、自由端**平移**随动（长度不变）；
  远端为固定锚点且保持同轴 → 节点沿该锚固管线**滑动**，管段长度按实际距离吸收
  （= 在既有管线上重新切分，子段长度和守恒，柔性/刚性段皆然）；
  离开管轴 / 越过锚固端折返 / 闭环尺寸不一致 / 两端皆硬锚 → 返回 `{ok:false, reason:...}`
  拦截，绝不静默拉断。`setSegmentLength` 的冲突原因会附 `_axisHint`：
  移动端位于多向交点时提示改选基准端或调另一侧相邻段。

### 两种锚点：硬固定锚（◆） vs 图纸拐点锚（◇）—— 刚性段整体平移（2026-09-15）

**问题**：改总管/立管长度时，用户只是移动它上游的三通（T-N1），却被
「改长被拒：移动将使管段离开原管轴弯折」挡住。根因是 `_propagate` 把所有
`fixed` 端点都当成墙，而 `fromPlan` 会把**平面图上的每一个链端点/折点**都标 `fixed`
（主管/支管折角、链末端），它们并不是用户设置的真墙。

**契约**：`fixed{}` 仍是"传播计算中的已知点"，新增 `hardFixed{}` 标记**真墙**：

| 类别 | 来源 | 传播时行为 |
|---|---|---|
| ◆ 硬固定锚 `_isHardAnchor(id)===true` | 用户【固定】/ 水源 `source` / `fromPlan` 的 **front 链**端点与 SRC | **墙**：方向不符 → 拒绝并点名；不随动 |
| ◇ 图纸拐点锚 `fixed && !_isHardAnchor` | `fromPlan` 的主管/支管折点、链末端 | **可整体平移**：连同下游整链一起平移，**管长与方向保持不变** |
| 自由接头 | 未固定 | 整段平移（长度不变） |

- `_isHardAnchor(id)`：`source` 类型恒为 true；否则看 `hardFixed[id]`。
- **刚性段（`rigid:true`）只允许整体平移，禁止拉长/缩短/旋转/折弯**——
  这正是"三通沿总管轴滑动 → 支管整体跟随"的实现方式：平移不改 `seg.length`/`seg.dir`。
- `_propagate` 五分支：① 自由端 → 整段平移；② 零长接驳段 → 保持重合随动；
  ③ 两端已知 + 同轴 + 长度不符 → 沿锚固管线**重新切分**（吸收，两侧此消彼长，和守恒）；
  ④ 方向不符 → **硬锚拒绝**（点名 `固 定端 X 使管段 Y 无法保持长度/方向`）/ **图纸锚整链平移**；
  ⑤ 折返/越过锚固端/环形闭合不上 → 拒绝。另有 `releasedOnce{}` + 20000 步上限防抖/防挂死。
- **`_axisGuard(fittingId, newPos)`**（直管轴向守卫）：对相连管段中"共线对数最多的那条轴"
  取管轴，移动后离轴 > 0.05m 即拒绝——防止「改长」把三通推离主管轴。
  **`moveFitting` 与 `_applyLenMove` 落位前都调用它**（同一口径），避免绕过。
- **分类拒绝只针对硬锚**：`setSegmentLength` 里只有 `_isHardAnchor(moveFitId)` 才按"它是锚点"
  直接拒绝；**显式指定的图纸锚（◇）一律放行尝试**，几何上真做不到时才由 `_propagate`
  给出**真实冲突原因**（如"固定端 E-P1 使管段 S1 无法保持长度/方向（会弯折 7.1°）"）。
  ★ 旧代码用 `explicit || _isHardAnchor()` 并把消息硬编码成"是固定锚点（◆）"，
  于是面板提示写「◇图纸拐点锚 → 允许随动平移」、消息却回「是固定锚点（◆）」——自相矛盾，已修。
- 锚点视觉：叠加层实线菱形 = ◆ 硬锚，**虚线菱形** = ◇ 图纸锚（图例同步）。
- API：`_isHardAnchor` / `_applyLenMove(segId,len,moveEnd)`（单次尝试，含轴守卫+传播+回滚）/
  `_axisGuard` / `hardFixed`（`serialize`/`deserialize` 均携带；老存档缺 `hardFixed` → 按"全部保守视为硬锚"迁移）。
- **端口**：每个配件有带方向的接口（方向/口径/占用态）；占用接口拒绝重复接管；
  口径不符返回 `needReducer`（提示需异径配件）。
- **几何辅助**（工程坐标统一容差）：`_projOnSeg`（点投影）、`_segIntersect`（两线段求交）、
  `_elevCompatible`（高程一致性）、`_midObstruction`（延伸路径中途交点检测）。
- **叠加层**：`g.cn-layer` 与轴测图同一 SVG，CSS transform 自动跟随缩放平移。
- **持久化**：`localStorage` 键 `runye_construction_net_v1:<plotId>`；`serialize` 带源数据
  几何签名 `sourceKey`，签名不符（用户改了平面方案）时置 `_legacyMismatch` 保留旧数据但标记不自动套用。
- **不回写**：`window.tlDiagramData` 原平面数据任何操作后保持字节不变（两个冒烟均有断言）。

### 本轮 5 项修复（要点）

1. **真实高程 / 显示层高分离**：`fromPlan` 主管 `z=-1`、支管 `z=0.3` 仅作绘制；
   `elevation` 默认 `null`。延伸接管需两端高程**已确认且相同**，否则拒绝（提示「未确认」/「高程不同」）。
   改图上展开高度（`z`）不改变 `elevation`。老存档迁移：原 `z` 保留为显示参数，`elevation` 默认未确认。
2. **目标端点驳接**：命中目标管端点时区分「普通自由管端」与「已有多接口配件」——
   前者按方向/口径补口对接（共线=对接，相交=弯头），后者只复用面向延伸方向（`-d`）的空接口，
   不重复占口、不给阀门/三通硬加接口；`a`/`b` 两端朝向均按延伸侧正确生成新端口。
3. **中途交点检测**：延伸路径全长扫描中途交点；**同高程**中途相交 → 阻止直接延伸（`midObstruction`）；
   高程**未知**不能判定可跨越（按同层阻挡处理）；已确认**不同高程** → 放行并标注「空间交叉（非连接）」。
   工程坐标统一容差，不使用 SVG 交点。
4. **边界修剪（真修剪）**：支持「交叉管截断」——在直管与边界管交点处截断，只删选中侧，
   保留另一侧长度/口径/材质/系统归属；新截断点建立**自由端**（不生成三通）。
   被删侧含配件/多分支/固定锚点 → 拒绝并列出影响范围（不静默连带删除）。
   高程未知/不同、交点过于靠近端点（<0.05m）、无交点 → 拒绝。修剪与引用更新为**单事务**，失败完整回滚。
5. **预览无副作用**：`planExtend`/`planTrim` 纯计算；`seq`（含 `tee` 序号）、接口、管段、约束、
   `notes`、撤销栈在预览期间零变化；稳定 ID 仅在确认提交时分配。预览后模型若变化，
   `applyExtend` 经 `_stalePlan` 重新校验，拒绝过期计划（`stale`），不残留半连接/切分管段/占用接口。

### 2026-09-15 追加：消除「改长被拒：移动将使管段离开原管轴弯折」的误报

用户场景：改总管 `S151` 长度 → 程序准备移动三通 `T-N1` → `T-N1` 下游连着刚性段 `S121`，
被直接报「弯折」。**S121 是刚性段没错，但用户只是移动它上游的三通，S121 应整体平移。**

1. **根因**：`_propagate` 把 `fixed` 里的图纸链端点/折点（`fromPlan` 标出的）当成了墙。
   修复：拆出 `hardFixed`（用户固定 / 水源 / 施工起点 / front 链），**只有硬锚才是墙**；
   图纸锚随下游整链平移，刚性段 `length`/`dir` 保持字节不变（见"两种锚点"一节）。
2. **改总管轴上的三通** → 自由端、阀门、弯头、相连刚性段全部**整体平移**；下游连接不破。
   两端皆硬锚的总管改长 → 三通沿轴滑动，两侧段一侧增长另一侧缩短（在既有管线上重新切分，和守恒）。
3. **只在真正做不到时拒绝**，且点名冲突端：`无法保持长度/方向（会弯折 N°）` / `将越过锚固端 X` /
   `环形约束…闭合不上`。绝不因为"它是图纸锚"而分类误拒。
4. **保留全部真实拦截**：离开管轴（`_axisGuard`，`moveFitting` 与 `_applyLenMove` 同口径）、
   改变刚性段方向/长度、推过锚固端折返、闭环尺寸不一致、两端皆硬锚、环形约束不收敛。

## 四、已知限制（**未实现**项明确标注）

1. `fromPlan` 连接关系靠**几何容差归属**（RISER_TOL=30 图纸单位），总管/主管埋地段的
   真实连接与标高为推断，面板与模型 `notes` 有「待确认」标记，未确认前不擅自补连。
2. **"硬锚 vs 图纸锚"是启发式划分**：`fromPlan` 把 front 链端点与 SRC 视为硬锚，其余折点
   视为图纸拐点锚。若将来引入"用户点选的施工起点/地块边界锚"，需补进 `hardFixed`，
   否则该处会被当成可平移的图纸锚。
3. **竖向 / 偏移接管未实现**：两端真实高程不同（或一端未确认）时**拒绝**接通，
   不生成斜接/立管；需人工分段或后续实现。
4. **自动异径配件未实现**：口径不符只返回 `needReducer` 提示，不自动插异径/大小头。
5. **中途同层交点**第一版为**保守阻止**（不自动改选目标、不偷偷生成三通、不绕行）；
   需人工先把该交点处理掉或改选该管为目标。
6. **修剪第一版**仅支持单一直管截断 / 单段自由支管删除；被删侧含配件、多分支或固定锚点一律拒绝。
7. 管段长度 = 节点中心到中心，未扣配件占位长度（实际切管需减管件插入损耗）。
8. 竖直段（立管展开高度）是表达参数，改其"长度"改的是图纸展开量，非真实埋深。
9. 撤销栈不跨刷新持久化（恢复的是最后保存态）。
10. 阀门/三通用通用符号 + 文字标注，与参数编辑约定一致。

### 交互（清单式，主入口）
- **【新建起始管道】**（唯一保留的画布拾取步骤）：点图拾取施工起点（工程坐标）→
  左栏选型号/方向/长度 →【预览】→【确认】。起点自动固定为锚点，终点为自由端。
- **「施工顺序清单」面板**（`st.net.assemblyLog` 渲染，有序列表，随快照/撤销/序列化走）：
  每添加一件自动记一行（`kind: 'start'|'connect'`，`text=plan.summary`），↩ 撤销整行回退。
- **「添加下一件」三步表单**：
  - ① 接装点下拉：自动枚举全部**空接口** + **自由管端**（endpoint 单段单口占用 →
    隐式朝外口续接，标注「自由管端 E-xx（Ø110）· 朝外续接」）；
    **点图中白圈空口 / 管端白圈 = 同步预选该项**（`st.assyPort`）。
  - ② 接什么：【接管道】【接三通】（选中语义，可连续添加同类）。
  - ③ 参数：型号下拉（按接装点口径筛选）+ 长度/方向（管道）或分支方向（三通，
    默认沿口朝向垂直；管端默认沿管轴向外）→【＋ 添加到清单】**一键提交**：
    内部仍走 `planConnect → runTx(applyConnect)` 两段式事务（一步撤销）；
    被拒原因（口径不符/方向规则/接口占用…）在清单内联红字显示，模型零变化。
- **接口详情**：点空口/配件 → 左栏显示口径 / 体系（PE-外径/DN-内径）/ 材质 / 连接方式 /
  朝向（工程角）/ 对接接口（`portInfo` 读取）。旧接口无体系标注时显示「未标注」；
  体系或连接方式双方都已标注且不相容 → 拒绝接通。

### 模型（network-model.js v2）
- `planStartPipe` / `applyStartPipe`、`planConnect` / `applyConnect`：两段式，
  预览零副作用（不占稳定 ID/seq），提交前复核源配件位置（stale 拒绝），事务内一步撤销。
- 自由管端续接：提交时在端点**隐式新增朝外端口**（不占用原管口），与既有 applyExtend
  endpoint 模式同思路。
- 接口 v2 字段：`system`（口径体系）/`material`/`conn`（连接方式）/`kind`（straight|branch）；
  配件 v2 字段：`productId`（目录型号）、`placeholder`（本体占位长度，米）。
  v1 存档载入自动迁移补齐（null/0），validate 仅对装配件巡检接口数契约
  （阀/弯/异径=2、三通=3、封堵=1）。
- 方向规则（工程坐标）：三通分支口必须垂直于直通轴（90°）；弯头出口与来流夹角必须
  等于产品固定角度（45°/90°）；阀门/异径/封堵沿现有接口方向。
- 长度语义：`length`=节点中心距；对接产生 `kind='joint'` 接头段（刚性，长=两端各占
  本体占位之半）；接管段 `piece`=管件净长（中心线 = 净长 + 半占位）。
  `computeStats` 新增 `placeholderTotal`（占位合计）与 `cutRef`（下料参考 = 中心线总长 −
  占位合计，估算值，非下料单）。
- serialize 版本升为 **2**（v1 存档仍可载入迁移）；方案/地块隔离与旧快照归档机制不变。
