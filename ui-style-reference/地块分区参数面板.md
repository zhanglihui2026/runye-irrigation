# 地块分区参数面板｜样式基准

**状态：已确认基准。** 本记录于 2026-10-15 根据当前源码核对。它用于保存面板尺寸、布局和代码归属，后续修改先查本页，再按“代码定位”进入实际实现。

## 尺寸与布局

| 项目 | 当前基准 | 实现说明 |
|---|---:|---|
| 桌面侧栏宽度 | 默认 `clamp(272px, 20vw, 318px)` | 分区与右侧画布共用三列网格；拖动中间 10px 分隔条时，侧栏跟随变宽或变窄。用户拖动后的宽度由分区容器上的 `--pp-side-w` 覆盖默认值。 |
| 面板内容区高度 | `calc(100vh - var(--fn-nav-h))`，最小 `520px` | 桌面布局由页面主体网格确定。参数超出可视高度时，在面板内容栏内部纵向滚动。主程序工具栏宿主会按宿主布局接管主体高度。 |
| 面板主内容内边距 | 主程序模式 `10px` | 参数行的横向内容宽度是面板宽度扣除左右内边距及边框后的可用空间；不应把它误认为固定宽度。 |
| 参数标签列 | `84px` flex 基准 | 只用于参数行标签；输入框与单位在其右侧排列。 |
| 输入框宽度 | **固定 `64px`** | 包含边框；`flex: 0 0 64px`，不会随侧栏拖拽拉伸。原生输入和 Shoelace 代理控件使用同一宽度。此前 40px、60px 是讨论中的试值，当前源码已落实 64px。 |
| 输入框高度 | **固定 `24px`** | 原生输入 `height:24px`；Shoelace 使用 `--sl-input-height-small:24px`。 |
| 参数行高度 | `min-height:27px` | CSS 最小行高，不是固定高度；内容和 padding 可能使实际行高增加。基础行内边距为上下 `2px`、左右 `12px`。 |
| 行内间距 | `5px` | 参数标签、控件、单位之间的 flex 间隔。 |
| 参数组间隔 | 视觉示意约 `20px` | 属于组间留白，不包含在单行 27px 最小高度内；具体组由面板结构决定。 |
| 扬程计算区 | 宽度 `100%`，最大宽度 `100%` | 在 CAD 主面板中占满面板内容宽度；文本允许换行，不以单行裁切。 |

上述侧栏宽度是桌面默认响应式范围，不等同于所有屏幕或用户拖动后的固定宽度。小屏断点、折叠状态和不同宿主视图会应用各自的布局规则。

## 样式与代码职责

面板在普通页面和主程序 CAD 工具栏中复用同一组 DOM 内容，但运行容器不同。因此源码里存在布局适配和 CAD 镜像样式；它们不是同一皮肤被多份随意覆盖：

1. **结构与字段**：[`index.html`](../index.html) 内 `#pipePlanSection`、`#ppSide`、参数行字段和 `#ppCalcDetail`。字段 ID 是计算与输入同步契约，改样式时不要重命名或删除。
2. **面板皮肤及参数控件**：[`mod/ry-panel.css`](../mod/ry-panel.css) 的 `#pipePlanSection .pp-side` 规则组。这里管理参数行、84px 标签列、64×24px 输入控件、单位、计算式换行和主程序模式内边距。
3. **主体网格与默认侧栏宽度**：[`mod/style-01.css`](../mod/style-01.css) 的桌面 `#pipePlanSection > .pp-body` 网格规则。三列分别为侧栏、10px 拖拽条和画布；未拖动时侧栏回落到 `clamp(272px,20vw,318px)`。
4. **拖拽行为**：[`mod/inline-19.js`](../mod/inline-19.js) 注入 `.pp-grip-side`，拖动时在 `#pipePlanSection` 上写入 `--pp-side-w`；双击恢复 CSS 默认宽度。
5. **CAD 工具栏宿主适配**：[`index.html`](../index.html) 的 `#ryCadTwinCss` 是由生成脚本维护的 CAD 选择器镜像，后续还有主程序宿主的布局接管规则。它用于节点移动到 `#ryCadSide` 后的作用域适配；应通过生成器更新，不能只编辑生成块或手工删除镜像。
6. **公共布局辅助**：[`mod/style-01.css`](../mod/style-01.css) 的 `body.ry-tool` 规则负责主程序下分区主体的网格位置和可伸展布局，不负责重复定义参数控件的皮肤。

相关样式表加载顺序会影响不同宿主的级联。调整前先检查普通页面和 CAD 工具栏两个实际渲染位置，并确认生成镜像仍与源 CSS 同步。

## 维护流程

- 改动尺寸或视觉样式时，先改 `mod/ry-panel.css` 或对应的布局源文件，并同步修改本档案与示意图。
- 若源样式影响 CAD 镜像，先按 [`scripts/refresh-cad-twin-css.cjs`](../scripts/refresh-cad-twin-css.cjs) 的预览与摘要校验流程生成，再应用更新；不要照抄示例占位摘要。
- 若变更了页面资源版本或 Service Worker 缓存清单，按项目发布约定同步更新；纯文档修改不需要改缓存版本。
- 只有在目标浏览器中检查了实际渲染后，才把新的实际视觉结果记为验证完成；CSS 声明本身只能证明源码基准。
