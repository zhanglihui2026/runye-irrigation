使用说明

本期功能范围

这里的数字化建模指参数化节点建模：支持直线、圆形和方形，拾取与连线，以及直线路径的圆形／矩形截面放样。预览为封闭实体网格，不含管壁厚度、水力校核或工程量计算。

模型使用未标定的局部单位，不自动对应米或毫米。模型只保留在当前页面内，切换顶部导航不会清空，刷新或关闭页面会清空。本试验区不读写灌溉设计、地块库及材料清单；顶部“三维建模”是另一个待规划入口。

一、图形拾取（左侧视图）

  1. 点击工具栏「直线 / 方形 / 圆形」，在视图中按下并拖拽即可绘制对应图形。
  2. 点击「选择」工具，再点击视图内任意图形即可拾取该图形（高亮显示）。
  3. 用「平移」工具或视图区右键拖拽可平移；滚轮缩放；「重置视图」恢复默认。

二、参数调节

  1. 选中图形后，左下「参数调节」面板出现对应参数。
  2. 尺寸参数（半径 / 宽高 / 长度）支持数值输入 + 滑块两种方式，修改即时生效。
  3. 参数自动容错：半径、长度、宽高不允许为负数，越界自动修正。

三、电池节点连线（右侧）

  1. 点击「＋ 拾取电池」创建拾取图形节点，点击「＋ 放样电池」创建放样圆管节点。
  2. 在「拾取图形」电池上点「拾取图形」按钮，再回到左侧视图点选一个图形，即把该图形存入此电池。
  3. 用鼠标从「拾取图形」电池的输出端（绿）按住，拖到「放样圆管」的输入端（蓝）建立连线：直线 → 放样路径；圆形/方形 → 放样截面。
  4. 同一输入端只保留一条连线；点击连线本身可删除该连线。
  5. 节点标题栏「×」可删除节点；工具栏「清空节点 / 清空连线 / 重置运算」分别对应相应操作。

四、成果预览

  1. 路径与截面都绑定后，左侧「三维预览」实时显示放样圆管 / 方管实体。
  2. 在三维预览区拖拽可旋转视角，滚轮缩放。
  3. 缺失任一输入时，节点与预览区提示「缺失输入数据」，不会报错或崩溃。
