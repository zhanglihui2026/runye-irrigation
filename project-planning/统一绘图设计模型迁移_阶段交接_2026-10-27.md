# 统一绘图设计模型迁移：阶段交接

更新时间：2026-10-27

## 当前结论

迁移已建立规范绘图模型和多地块组适配器，并把一批二级成员编辑接入规范事务。新组快照附带规范模型；组恢复现在优先从该模型投影旧编辑器字段，旧快照缺少规范字段时仍走兼容导入。单地块快照读写、主要二级编辑和一批三级用户编辑已接入规范事务；剩余写路径、权威切换、旧字段退出和系统验收仍未完成。

恢复时先检查本文件所述工作区状态与当前代码，确认功能简化对迁移范围的影响，再继续；不要假定本文记录仍与后续工作树一致。

## 已完成

- `core/drawing-design-model.js` 提供无界面规范模型、对象校验、按地块和组标识的乐观修订事务。
- 地块修订号现只追踪二级源设计；三级 `generated` 与几何绑定编辑仍存入规范对象，但写入它们不会推进源修订，因此不会让生成物在自身提交后变旧。组级总修订继续记录整笔模型事务。
- 单地块三级节点/连线、手工管线和自动编辑的用户写入接入规范 `updatePlot`；工作区将连续编辑合并后提交，节点拖动松手时补写最终桩号。提交绑定当前地块、二级设计字段及生成输入/几何签名；恢复通知、组态、会话态改径和旧无签名生成物不写入此事务。
- 单地块存档恢复在改动当前地块锚点前校验有签名的三级生成物；签名与该存档输入不匹配时整体拒绝，旧无签名档仍走兼容路径。保存时合并 canonical 更新后把 `generated.sourceRevision` 对齐到事务实际得到的地块修订，避免三级编辑只改变总修订时误使生成物过期。
- 单地块确认分区角度已接入 `updatePlot`：先核对 canonical 与编辑前的二级设计，成功后提交新分区并清除过期三级派生/编辑；CAS或前像不符则恢复编辑前槽。预览态不写入；没有 canonical 的首次/旧项目仍走兼容路径。
- 单地块自动布管已接入同一 canonical 事务桥：捕获生成前设计前像，校验后提交新管网；拒绝时恢复管网槽并刷新方案、简图和材料显示；组态保留既有成员批次路径。
- 单地块清除管路已纳入 canonical 事务，管线、水源、阀门、遮蔽及ID重置作为一次提交；前像冲突时恢复旧槽，组内清除维持原成员批次路径。
- 单地块确认重新分区已纳入 canonical 事务，面积锁解除、切线重置和管网清空一并提交；拒绝时恢复编辑前状态，组内逐块保留现有成员事务。
- 单地块自动划分模式已纳入 `updatePlot`：canonical 成功后才更新 `runye_zone_auto` 共享默认；拒绝时恢复旧模式，不写共享默认值。
- 单地块放置水源与阀门已纳入 canonical 管网事务，提交拒绝时恢复编辑前状态；组内逐块仍使用成员槽事务。
- 单地块切线拖动现于松手时提交canonical，预览期间不写入；主画布、移出画布结算和三级边界桥共用同一提交与回滚路径。
- 单地块三级阶梯切口拖动现于松手时提交规范三级派生状态；提交拒绝时恢复拖动前的阶梯覆盖和三级几何快照，多地块逐块路径仍使用成员阶梯事务。
- 单地块面积锁定、网格重置和切线微调现通过统一二级事务提交；拒绝时回滚前像，整组总览禁止直接重置共享网格。
- 二级规划页的本地撤销现把恢复后的单地块状态写回规范事务，组内逐块撤销写回成员槽；规范拒绝时保留待撤销历史并恢复当前画面。工程级 Ctrl+Z 仍走完整快照恢复路径。
- 工程快照恢复的单地块规范投影现在保持纯函数：只有当前地块锚点成功写入后，才发布快照中的规范模型；旧格式或组快照会清除遗留的单地块规范影子，避免锚点拒绝时规范模型先被半恢复。
- 多地块组恢复新增纯预检：带规范模型的组快照先完成成员绑定、旧字段投影和规范再导入校验，工程加载器在地块锚点写入前调用预检；已知无效组快照不会先改写其余工程状态。
- 单地块画布的管线显隐切换现在捕获二级设计前像并提交 `updatePlot`；拒绝时恢复显隐状态，成功后同步三级显示和材料汇总。组内逐块仍用成员事务，整组视图继续只读。
- 规范事务拒绝的单地块/组成员编辑现会丢弃该次刚入栈的撤销快照，避免后续撤销越过失败操作；Undo 提交自身失败时保留待撤销历史，三级阶梯拖动失败也清理其预览历史，复位路径不误删旧历史。
- 多地块组遗留的逐块三级保存桥现在把 `RyTlNodes` 的节点/连线快照写入成员 `tlState.nodes`，并保留已有辅助状态字段；此前该桥重建 `tlState` 时会漏掉节点层，导致规范组适配器后续导入/导出无法保留这类三级编辑。已移除的逐块交互入口保持移除。
- `plot-editor.js` 的组成员批量保存不再于规范提交桥缺失时直接改写 `ge.slots`；缺失桥接现在拒绝提交，由现有编辑路径执行回滚，避免绕过 `updatePlot` 和组适配器。
- 组快照导出遇到适配失败或 canonical 与兼容投影不一致时现拒绝导出；`runyeSaveProject` 检测活动组缺少有效 canonical 快照时停止写盘，避免把不完整 `groupPlan` 保存成新档案。
- 组成员事务若适配后没有规范字段变化，不再把兼容槽直接写回活动组；部分批次只把规范投影确实改变的成员槽落回，避免未建模的旧字段绕过规范权威。
- 成员槽快照及既有设计继承/恢复按地块边界裁剪管线时，共用ID与隐藏映射同步逻辑：每条原管线的首段保留原ID，额外片段分配新ID，隐藏状态随片段传播，防止裁剪改变管线数量后ID/隐藏标记错配；生成施工图的替换式分发继续按既有规则重建新ID。
- 三级节点沿管移动（画布拖动与桩号精确输入）统一由 `moveNode` 变更订阅延迟提交规范单地块模型，移除指针松手的重复直写；组态仍由成员/组边界保护拒绝该单地块提交。
- 单地块三级图生成成功后，生成器现在先记录当前二级输入签名，再调用既有三级规范事务桥；该桥继续校验地块身份、二级设计前像与生成几何签名，组编辑活动时跳过单地块提交。页面脚本查询版本和 Service Worker 缓存版本同步递增。
- 单地块保存遇到同身份规范模型时，先同步签名有效的三级运行态；旧字段导入只用于确认内容一致，不再覆盖规范模型。保存从规范模型投影兼容字段，绑定模型与旧投影不一致或投影异常时拒绝保存；没有既有规范模型的历史/首次迁移仍可从旧快照引导。
- 组快照恢复预检现会把规范模型投影到旧字段后再次导入，并比较往返后的完整规范内容；设计与地块修订号按版本元数据归一化。往返漏字段或语义变化时，在修改工程状态前拒绝恢复。
- 组三级适配器投影规范节点状态时，节点为空会显式删除兼容 `tlState.nodes`，同时保留同一状态对象中的阶梯或其他字段；这使“规范空节点”能通过恢复往返比对，而不会被旧节点残留阻断。
- 工程载入现明确返回恢复成功/失败；组规范状态恢复被拒时报告失败。Ctrl+Z 仅在载入确认成功后移动历史指针，失败时保留原撤销位置和目标快照供重试。
- 单地块快照没有 `groupPlan` 时，组恢复函数会清空当前组并按约定返回 `false`；工程载入现在只把“存在组快照但恢复失败”视为载入失败，避免单地块载入和撤销被误拒。
- `core/drawing-design-group-adapter.js` 在旧多地块组快照与规范模型间转换，绑定成员身份和几何，并处理成员三级状态、阶梯切口覆盖及旧格式投影。
- 多地块组的分区角度、切线、重新分区、分区模式、面积锁定、布管清管、网格重置和阶梯切口等二级写入已部分接入成员事务。
- 普通成员编辑保留三级阶梯覆盖；阶梯覆盖与分区槽自身的切口覆盖分别保存。
- 三级工作区的阶梯切口复位会先请求桥接事务；桥接失败时停止复位。
- 本轮补齐二级逐块态的水源与阀门落点写入：先捕获成员前像，再通过 `ppCommitGroupMemberEdit` 走既有 `grCommitGroupMemberSlots`/`updatePlot` 桥，拒绝时回滚该块槽。整组模式在拾取分支之后统一拦截非只读编辑，避免脚本残留模式把水源或阀门写入临时合并视图。
- 组快照导出时附带 `canonicalDrawingDesign`，规范事务修订号随快照保留。
- 新组快照恢复时校验规范模型及项目/组/成员身份，再由组适配器投影到旧编辑器字段；规范字段存在但无效或无法投影时拒绝恢复。没有该字段的旧组存档继续走旧格式导入。
- 组撤销恢复现在复用恢复预检已验证的规范设计，不在写入编辑器状态后再次导入；避免二次导入失败时清空规范模型却仍报告恢复成功。
- 自动恢复、AI 回程与施工图恢复现在都检查工程载入结果；拒绝载入时不设置“已恢复”标志、不消费回程标记，也不安排后续重放。
- 当前地块锚点改为在完整快照保存成功后写入；存档失败时不发布指向新地块的锚点。
- 历史组存档（无 canonical 字段）现在也会在修改工程状态前完成适配器导入和规范模型校验；恢复阶段直接安装该预检结果，避免旧组档导入失败后留下部分恢复状态。
- 有效地块绑定的历史单地块存档（无 canonical 字段）现在会在锚点提交前尽力导入并校验规范模型；导入成功才在锚点提交后发布到运行态，导入失败仍按原兼容路径恢复，不降低旧档可打开性。
- 单地块 canonical 存档恢复时，旧格式投影现在会再导入规范模型并比较完整内容（忽略事务修订元数据）；投影丢字段或改变语义时在工程状态变更前失败关闭。
- 组级撤销继续复用包含 canonical 组模型的工程快照及标准恢复预检；撤销快照捕获现在先清理可能由异常退出遗留的临时键，并要求本次工程快照保存明确成功，避免把旧临时字节当成新撤销状态。
- 撤销仍依赖 `groupPlan/ge.slots` 兼容投影；单地块工程存档和三级各编辑层尚未迁为规范模型权威。
- `mod/inline-12.js` 现为有效地块绑定的非组工程快照附加 `canonicalDrawingDesign`，并按地块稳定身份导入；同一运行时地块连续保存时以 `updatePlot` 递增规范修订。恢复时先验证模型、项目 ID、地块 ID 和旧格式投影，任一失败则停止整份存档恢复；没有 canonical 字段的历史存档保持原路径。UI 写入仍经旧字段，因此尚未完成单地块权威切换。
- 每地块 `runye_plot_design_v1:<plotId>` 继承档同步携带 canonical 模型。`plot-editor.js` 在组内继承时若发现该字段，先验证单地块项目/成员身份，再投影出兼容管网字段，之后仍执行原有成员轮廓匹配、质心平移与管线裁剪；canonical 存在但无效或不能投影时拒绝此候选，不用它的旧副本兜底。历史档没有该字段时维持旧导入行为。
