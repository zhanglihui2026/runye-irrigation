# 统一绘图设计模型迁移 · 权威切换分批实施规划（2026-11-02）

> 依据：`统一绘图设计模型迁移_阶段交接_2026-10-27.md`「尚未完成」5 项 + 合并调查（v896 时点）。
> 性质：**规划文档，未动工**。任何一批动工前须用户/会话确认；每批独立可回归、独立发版。
> 总原则：**先审计后动手、先组级后单地块、先验收后停写**。旧字段在任何批次都保持只读兼容，停写是最后一批。

## 背景一句话

canonical 规范模型（`core/drawing-design-model.js` + 3 适配器 + inline-12 事务收口）已建立，单地块快照、主要二级编辑、一批三级编辑、组撤销批次（`grCommitGroupMemberSlots`）已接入；**但 UI 写入仍走旧字段（ppState/tlDiagramData 双轨），canonical 尚未成为唯一权威**——这是「总会有 bug」的结构性根源。

## 批次划分

### 批次 A · 剩余写路径审计与接入（工程量最大，先做）

- **目标**：盘点所有仍直写旧字段的 L2/L3 写入口，逐个改走规范事务（inline-12 既有收口），行为不变。
- **做法**：
  1. 纯审计（不改码）：grep 盘点 `tlDiagramData.*=` / `ppState.*=` 的写入口，产出清单文档（文件:行、写什么、现有事务路径、改法）；
  2. 按风险分小批接入，每小批过全闸 + CDP 探针回归（生成/编辑/撤销/恢复四路径）。
- **验收**：审计清单覆盖 grep 结果 100%；每小批 536 测试全绿；探针数据一致（canonical 与旧字段投影逐值相等）。
- **回滚**：单 commit revert。
- **预估**：审计 1 轮；接入视清单长度 2~4 小批。

### 批次 B · 组撤销权威收口（轻量，可与 A 并行）

- **目标**：组撤销恢复已复用恢复预检验证过的规范设计（交接文档 §50 已做），补验收即可。
- **做法**：探针覆盖「组撤销→恢复→再编辑→再保存」闭环，确认无二次导入清空路径。
- **验收**：整组撤销后规范模型修订号单调、成员槽全部回写；探针截图直证。
- **预估**：1 探针轮 + 1 发版。

### 批次 C · 单地块旧格式边界验收

- **目标**：核验初始化、切换地块、存档恢复、规范拒绝路径在旧档（无 canonical 字段）下的行为。
- **做法**：构造三类存档（纯旧格式 / 带 canonical / canonical 损坏），CDP 探针逐类走全流程。
- **验收**：纯旧档走兼容导入成功；损坏档整份拒绝并保留现状（不得半恢复）；切换地块后绑定隔离。
- **预估**：1 探针轮 + 修缺陷（如有）。

### 批次 D · 迁移系统验收（发版闸门）

- **目标**：兼容读写、保存恢复、撤销、旧路径退出条件四项整体验收，产出验收记录（project-planning/验收记录/）。
- **做法**：全量探针矩阵（含旋转重生成、地图回传、DXF/材料/水力四产物比对）在真实浏览器跑一遍。
- **验收**：所有产物 canonical 口径与旧口径一致；CAS 拒绝路径全部有显式反馈（v895 已把空结果与失败原因两个静默口子堵死，此批延续该标准）。
- **预估**：1~2 轮。

### 批次 E · 旧字段停写与清退（最后，最敏感）

- **目标**：UI 写入切到 canonical 唯一权威；旧字段降级为「只读投影 + 存档兼容」。
- **前置**：批次 A~D 全部验收通过且线上稳定至少一个版本周期。
- **做法**：写路径逐模块切（与批次 A 同清单反向核对）；停写 ≠ 停读，旧字段消费点保持。
- **验收**：关掉旧字段写入后全功能回归；旧存档打开不报错。
- **回滚**：单 commit 切回双写。

### 批次 F · AOCI Maintain 收尾

- **目标**：代码最终稳定后按 AGENTS.md 执行一次 AOCI 维护（交接文档明示：期间不在每个中间修改后重复维护）。

## 风险与纪律

- 每批遵守发布纪律全闸（check.cjs + node --test + check_publish_refs + lint），版本号接续前 grep 空号。
- canonical 字段新增/变更必查四个适配器（legacy/group/level3 + inline-12 事务），漏一处即 §2.5 类静默回滚（总管清单教训）。
- 探针一律真实用户路径（v895 七轮经验），静默失败口子必须显式反馈。
