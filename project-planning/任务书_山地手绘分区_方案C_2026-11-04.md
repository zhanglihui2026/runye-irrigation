## 0. 结论先行

方案C 是为**山地不规则地块**新增一套"沿任意角度手绘折线、按面积切分"的分区能力。核心矛盾是：

> 现役分区线是 `partitionCuts = {x:[...], y:[...]}` 横竖直线网格（自动网格 / 拖横竖线 / 合并相邻区），**只能矩形网格**，横跨山地地形时亩数对不上。方案C 需要的是**任意角度多点折线 + 边线吸附 + 实时面积反馈 + 达标吸附**。

**本文档已把"面积划分细节"写实到可实施粒度**（§3），实施方只需按函数签名落地，不需再推敲交互语义。

## 1. 目标与验收标准（一句话版）

在山地模块 `#tCanvas` 上，用户手绘一条**多点折线**把不规则地块切成若干区：

- 折线**端点吸附在地块边线上**（保证贯穿一刀切），**中间顶点拖到边线附近自动吸附**；
- 沿折线实时把地块切成左块＋右块，**面积守恒、不重叠不遗漏**；
- 实时显示每区亩数 + 距目标亩数差；
- 接近目标亩数（±5%）给**达标吸附**提示；
- 切分完成后可**锁定**（严格平移 + 面积保持）。

验收：手绘折线切割面积守恒；吸附命中；亩数实时正确；锁定后拖动面积不变。

## 2. 用户确认的参数（锁定口径）

| 项 | 值 | 说明 |
|---|---|---|
| 分区形态 | **折线为主，直线=2 点特例** | 任意角度多点折线，可贴合地形/等高线 |
| 切分方式 | **边界到边界一刀切** | 折线首尾端点吸附在地块边线上，贯穿切开 |
| 亩数约束 | 指定目标亩数（默认 10 亩）+ 实时面积 + 达标吸附 | 目标可输入 |

| 锁定 | **严格平移 + 面积保持** | 锁定后拖动仅平移、面积不变 |
| 画完 | 走现有流程 | 分区 → 调角 → 生成管线，不另造链路 |
| 数据方向 | `partitionCuts.hand=[{pts:[...]}]` 或 terrain-core `state.hand` | 见 §3.5（实现方向） |

## 3. 面积划分细节（本任务书重点，写实到可实施）

### 3.1 交互流程（面积是怎么"画"出来的）

面积不是直接手画的，而是：**用户画一条折线 → 工具沿折线自动把地块切成两块 → 鞋带公式自动算每块亩数**。

```
① 进入手绘模式（✏ 手绘分区）
② 落首点：必须在待切地块【边界】上（容差 = 画布最小边 × 0.02）
③ 依次连点：成多点折线（贴合地形）
④ 落定（双击 / ✓完成）：折线两端延长到边界 → 一刀切
⑤ 自动切分：left 留作继续切，right 入已切区 zones
⑥ 实时显示：切出区亩数 + 剩余区亩数 + 距目标差
⑦ 达标吸附：|当前亩 − 目标| ≤ 目标×5% → 变绿提示
⑧ 可继续画下一条线 / 撤销 / 重置
⑨ 锁定后：微调只平移、面积不变
```

### 3.2 折线的数据模型

```js
// 一条分割线 = 有序顶点数组（>=2 点），首尾在边线上
line = { id: 'hp_xxx', pts: [{x,y}, {x,y}, ...], locked: false }
// 已切区
zone = { id: 'hz_xxx', poly: [{x,y},...], mu: 亩数, locked: false }
// 手绘状态
state.hand = { targetMu: 10, lines: [line...], zones: [zone...] }
```

### 3.3 核心几何算法：沿折线切多边形

**复用已有**：`polygonAreaM2` / `sqmToMu` / `pointInPolygon` / `sanitizeRing`（terrain-core 现有，不改）。

**新增 `clipPolyByPolyline(poly, line)`** —— 把现有 zone-geometry 的「矩形 4 边半平面裁剪」泛化为「手绘折线 N 段逐段裁剪」：

```
对折线每一段 (A→B)：
  半平面裁剪：保留 叉积 d×(p−A) >= 0 一侧（d = B−A）
  left = poly 依次被每段裁剪的结果
  right = 反向折线再裁一遍（得到折线另一侧）
任一侧不足 3 点（未贯穿 / 退化）→ 返回 ok:false
返回 { ok, left, right }
```

**新增 `extendPolylineToRing(line, poly)`** —— 折线两端延长到地块边界（"一刀切"贯穿）：

```
首点沿「首点→次点」方向射出去，取与该方向射线相交且 t 最小的地块边作为贯穿点
末点同理沿「末点→次末点」方向延长
返回延长后的折线（首尾已贴边）
```

### 3.4 面积计算与达标吸附

```
面积：鞋带公式 polygonAreaM2(left) → sqmToMu 得亩数
吸附：|muL − targetMu| ≤ targetMu × 0.05  → 达标
实时预览：拖线时用 extendPolylineToRing + clipPolyByPolyline 现算，显示"切出区面积 + Δ"
```

### 3.5 数据持久化与归属（实现方向二选一，实施前与用户确认）

- **方向A（推荐，自包含）**：挂 terrain-core 的 `state.hand = {targetMu, lines, zones}`，随 `loadState/saveState` 走既有 `runye_terrain_module_v1` 存储（自动获得快照/回放）。
- **方向B（贴合原数据结构方向）**：存进 `partitionCuts.hand = [{pts:[...]}]`，与大田网格并存。

> ⚠️ 若选方向B，需与现役 `partitionCuts` 的读取方核对隔离，避免手绘折线被当横竖直线处理。当前实现草案（已还原）用的是**方向A**。
