SCHEME OVERVIEW

方案总览

本方案由「底肥、叶面喷雾、灌根营养」三大模块构成，覆盖从播种前土壤处理到收获前的全生育期，形成立体化植保与营养管理网络。

底肥方案

¥600 /亩
  • 播种前生石灰土壤消毒
  • 有机肥 + 复合肥 + 杀菌剂三位一体
  • 主攻：产量、黄曲霉毒素、生根

叶面喷雾植保方案

¥360 /亩
  • 苗前封闭 + 苗后除草
  • 控虫、杀菌、控旺、营养四位一体
  • 7 个关键节点，贯穿全生育期

灌根植保营养方案

¥640 /亩
  • 促根、防线虫、防地下害虫
  • 根腐/白绢病专防 + 中微量元素
  • 6 个节点，主攻荚果饱满度

APPLICATION CALENDAR

全生育期操作历 · 混配方案

把底肥、叶面、灌根三大模块按生育节点捏合成一张「操作历」：每个节点告诉你用几种、怎么搭配、哪些同桶、哪些必须分开；并整合了阶段与约周次信息。播后天数为参考值，按品种与天气微调。

混配通则：哪些能同桶，哪些必须分开

可同桶混配（一类桶一起喷 / 灌）

  • 营养最安全：磷酸二氢钾、硼钼、聚合磷飞防助剂、根际香土（氨基酸/寡糖）、铠仆（海藻）与杀虫/杀菌/调节剂基本都兼容，是「万能混配基底」。
  • 杀虫剂互混：氯虫苯甲酰胺（锐动）、甲维盐·茚虫威（铜拳）、虫螨腈·虱螨脲机理不同，可同桶。
  • 杀菌剂互混：秀艳、美得乐、拜亩乐、腾丰、地腾/苗乐乐可同桶（注意三唑叠加，见右栏）。
  • 杀虫+杀菌+营养+调节剂：各节点「叶面 8–11 种」即同桶一次喷施，原则可行。
  • 灌根类：水溶肥 ＋ 根际香土/铠仆 ＋ 苗乐乐 ＋ 剿灭/削线一般可同桶。

必须独立 / 谨慎

  • 除草剂独立：精异丙甲草胺、双氯磺草胺、烯草酮单独作业，不与杀虫/杀菌/营养混；苗前封闭播后 3 天内、墒情好时喷。
  • 生石灰独立：与底肥/化肥/菌剂间隔 ≥7 天，单独撒施；碱性强，勿与铵态氮、微生物菌剂同施。
  • 克菌丹（美得乐）谨慎：避免与强碱性（波尔多液、石硫合剂，本方案未用）及含铜制剂混；与常规中性药肥可混，现配现用。
  • 三唑控旺叠加：秀艳、拜亩乐、腾丰均含三唑/环丙唑醇，同桶会控旺叠加 → 保留 1 种或减量，防抑长过度。
  • 控旺总量：小胖子、适大进、妥控、金收可同桶但核算总量，烯效唑活性强尤需谨慎。
  • 杯混试验：多药混配前先做小样，观察絮凝/分层/发热/变色，无异样再大面积；现配现用、二次稀释、先肥后药。

KEY NOTES

关键技术要点与注意事项

⏱ 生石灰与底肥间隔

播种前土壤消毒用的生石灰，必须与底肥施用时间间隔至少 7 天，避免烧根与肥效损失。

🚫 化肥/杀菌剂勿触根

高富专、地腾等底肥成分严禁直接接触作物根系，须覆土并均匀分布于 10–30 厘米土层。

💧 苗前封闭看墒情

精异丙甲草胺、双氯磺草胺须在播后 3 天内、墒情适中时均匀喷雾，封闭除草效果最佳。

🌿 有机肥勿裸露

友擎有机肥撒施后尽量覆土，避免裸露于土壤表面造成养分挥发与流失。

🪴 灌根护根防病

根际香土、苗乐乐、削线等灌根产品主攻促根、防线虫与根腐/白绢病，是七彩花生荚果饱满的关键。

⚖️ 控旺贯穿全程

小胖子、适大进、妥控等控旺药剂在多个节点使用，防止旺长、促进矮节与荚果充实。
